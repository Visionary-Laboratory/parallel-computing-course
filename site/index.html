关于这门课

ABOUT THIS COURSE

模型中的一次矩阵乘法，如何变成 GPU 上高效执行的程序？这门课从并行计算的基本概念与性能模型出发，逐步介绍 CUDA、内存层次、Tensor Core 与异步流水线，并以 FlashAttention 和 3D Gaussian Splatting 为案例，连接算法、硬件与系统。
