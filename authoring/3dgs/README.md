# 3DGS 本地章节

本章为约 135 分钟的中文课程草稿：49 页主线、8 页深入阅读、3 道短填空与参考答案。按主题连续展开，没有划成三个固定课时。

## 编辑与预览

在仓库根目录执行：

```sh
python3 authoring/3dgs/build.py
python3 preview.py
```

访问 <http://127.0.0.1:4173/lectures/3d-gaussian-splatting/>。端口冲突时使用 `python3 preview.py --port 4174`。

- `content.py`：正文、标题、例题、答案、来源。`add(..., deep=True)` 表示深入阅读。
- `figures.py`：课程原创 SVG 图解。
- `model.mjs`：交互图使用的高斯、合成、Tile 与前缀和数值模型。
- `viewer.mjs` / `viewer.css`：交互与阅读、演示、打印布局。
- `build.py`：标准库构建脚本；不联网，不调用原网站的私有生成器。
- `check.mjs`：例题与边界情形的数值检查。

正文生成至 `site/lectures/3d-gaussian-splatting/index.html`，资源生成至 `site/materials/lectures/3dgs/`。同目录 `chapter.json` 是可供原作者项目迁入的结构化正文导出；应编辑 authoring 源文件后重新构建，避免只改生成文件。

## 课堂使用

- 阅读模式沿用已有讲义的课程侧栏、面包屑、主题分组与页内稳定链接；“逐页浏览”进入第一页，“从此页开始”从对应页面进入演示。
- “本讲内容”沿用已有讲义的逐页目录：页码、当前页高亮、滚动跟踪、自动展开的“本页要点”。窄屏有目录按钮；演示底部的目录与页码按钮打开同一个目录对话框。
- 普通演示保留课程导航，卡片内长内容可滚动；F 或全屏按钮切换专注演示。浏览器拒绝系统全屏时，仍保留页面内的专注布局。
- 右方向键、PageDown、空格先显示答案，再翻页；左方向键、PageUp先收起答案，再返回上一页。Home / End 跳到首尾。Escape 退出全屏或返回阅读。聚焦输入控件时方向键留给控件，打开目录时不翻动背景页面。
- 阅读 / 演示为可键盘操作的标签页。演示链接沿用 `?mode=slides&topic=页面ID`，深入阅读使用 `path=all`；兼容原草稿的 `mode=present`、`deep=1` 链接。模式切换与浏览器前进 / 后退保留当前主题。
- “主线 · 展开深入阅读”增加 8 页可选材料；收起时若正处于深入页，会回到前一主线页。正文、目录与演示页码保持一致。
- 代码框提供“复制代码”；图示链接可打开原 SVG。参考答案按钮随展开状态切换“显示 / 收起参考答案”。
- “导出本讲 PDF”与旧章节一样包含全部 57 个主题，并提供目录和可选参考答案。等字体和图片就绪后开启打印；浏览器中选择 A4、另存为 PDF、关闭页眉页脚。交互图保留默认静态画面（合成例显示最终结果），不导出逐帧动画。
- 三个交互图分别演示高斯形状、前后合成与 Tile 候选。不依赖 CUDA，也不作为 GPU 性能测试。

## 建议讲授节奏（合计 135 分钟）

| 主题 | 时间 | 讲授重点 |
| --- | ---: | --- |
| 从照片到新视角 | 8 分钟 | 确立任务，区分学习与渲染 |
| 高斯表示 | 20 分钟 | 由软覆盖进入尺度、旋转、不透明度与 SH |
| 三维到屏幕 | 18 分钟 | 中心、形状、局部投影近似与候选范围 |
| 像素颜色 | 18 分钟 | T 与 C 的更新次序；填空 ① |
| Tile 工作组织 | 24 分钟 | 同一组四高斯数据贯穿计数、Scan、排序；填空 ② |
| GPU 执行 | 25 分钟 | 所有权、shared 生命周期、done 与全块交接；填空 ③ |
| 学习场景 | 12 分钟 | 梯度路径、反向归约与密度控制 |
| 性能与总结 | 10 分钟 | 区分 N、M、K；完整成本与质量 |

休息可安排在主题之间。填空作答约 7 分钟，加上答案讨论约 9 分钟，已包含在上述时间内。深入页不计入主线预算。

## 验证

```sh
node authoring/3dgs/check.mjs
node --check authoring/3dgs/viewer.mjs
python3 authoring/3dgs/audit.py
```

数值检查覆盖 Tile 边界、空 Tile、零数量前缀和、排序范围、alpha 合成次序和高斯旋转。没有运行或声称运行 CUDA 实测。GPU 代码均明确标为教学伪代码。

## 与原发布仓库的关系

原仓库只含已生成的公开站点，教师的编辑项目尚未提供。此实现不修改原来的压缩 JS/CSS，通过一个单独的本地草稿导航脚本，从现有主页与侧栏链接至新章。原有六讲保持其原有阅读与演示应用。

本地草稿没有编号为第七讲，以免与其他作者的 FlashAttention 等内容发生顺序冲突。没有更新发布清单，也没有执行部署。后续正式整合应将本目录的内容与图示迁入原作者项目，并通过其 `pnpm pages:prepare` 流程重新生成公开站点。直接运行旧项目的生成器可能覆盖本地生成页。

方法依据 Kerbl 等 SIGGRAPH 2023 论文（论文 HTML 标注 CC BY 4.0）及官方实现；正文保留来源链接。所有图解与数值小例子均为原创。没有重新分发官方 CUDA 源码。论文概念与本讲简化代码之间的差别在相关页面明确说明。
