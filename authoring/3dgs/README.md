# 3DGS 本地章节

本章为约 135 分钟的中文课程草稿：49 页主线、8 页深入阅读、3 道短填空与参考答案。按主题连续展开，没有划成三个固定课时。

## 编辑与预览

在仓库根目录执行：

```sh
python3 authoring/3dgs/build.py
python3 preview.py
```

访问 <http://127.0.0.1:4173/lectures/3d-gaussian-splatting/>。端口冲突时使用 `python3 preview.py --port 4174`。

- `content.py`：正文、标题、例题、答案、来源。`add(..., deep=True)` 表示深入阅读。
- `figures.py`：课程原创 SVG 图解。
- `model.mjs`：交互图使用的高斯、合成、Tile 与前缀和数值模型。
- `viewer.mjs` / `viewer.css`：交互与阅读、演示、打印布局。
- `build.py`：标准库构建脚本；不联网，不调用原网站的私有生成器。
- `check.mjs`：例题与边界情形的数值检查。

正文生成至 `site/lectures/3d-gaussian-splatting/index.html`，资源生成至 `site/materials/lectures/3dgs/`。同目录 `chapter.json` 是可供原作者项目迁入的结构化正文导出；应编辑 authoring 源文件后重新构建，避免只改生成文件。

## 课堂使用

- 阅读模式沿用已有讲义的课程侧栏、面包屑、主题分组与页内稳定链接；“逐页浏览”进入第一页，“从此页开始”从对应页面进入演示。
- “本讲内容”沿用已有讲义的逐页目录：页码、当前页高亮、滚动跟踪、自动展开的“本页要点”。窄屏有目录按钮；演示底部的目录与页码按钮打开同一个目录对话框。
- 普通演示保留课程导航，卡片内长内容可滚动；F 或全屏按钮切换专注演示。浏览器拒绝系统全屏时，仍保留页面内的专注布局。
- 右方向键、PageDown、空格先显示答案，再翻页；左方向键、PageUp先收起答案，再返回上一页。Home / End 跳到首尾。Escape 退出全屏或返回阅读。聚焦输入控件时方向键留给控件，打开目录时不翻动背景页面。
- 阅读 / 演示为可键盘操作的标签页。演示链接沿用 `?mode=slides&topic=页面ID`，深入阅读使用 `path=all`；兼容原草稿的 `mode=present`、`deep=1` 链接。模式切换与浏览器前进 / 后退保留当前主题。
- “主线 · 展开深入阅读”增加 8 页可选材料；收起时若正处于深入页，会回到前一主线页。正文、目录与演示页码保持一致。
- 代码框提供“复制代码”；图示链接可打开原 SVG。参考答案按钮随展开状态切换“显示 / 收起参考答案”。
- “导出本讲 PDF”与旧章节一样包含全部 57 个主题，并提供目录和可选参考答案。等字体和图片就绪后开启打印；浏览器中选择 A4、另存为 PDF、关闭页眉页脚。交互图保留默认静态画面（合成例显示最终结果），不导出逐帧动画。
- 三个算法交互图分别演示高斯形状、前后合成与 Tile 候选；第2页另有输入输出可视化，含真实 COLMAP 点云与相机。不依赖 CUDA，也不作为 GPU 性能测试。
- 第1页在课件内播放原论文项目页的 Bicycle / Garden 场景视频，可切换、拖动进度和全屏；默认不自动播放，翻离页面或切换场景时暂停。视频直接使用官方 MP4 地址，需要联网；未复制或重新托管视频。加载失败时可在原位重试。PDF 用原创相机示意和观察问题替代播放器，保留来源。

### 备课时要走通的三个例子

1. **形状 → 局部 alpha（第17页）**：不旋转，横/纵标准差 2/1，o=0.8。分别计算中心、横移2、纵移2的 alpha：0.8、约0.4852、约0.1083。先问学生预测大小，再解释按宽度缩放的距离。此页是独立几何算例，红绿蓝合成例另行直接给定 alpha。
2. **列表 → 加载 → 消费（第32–36页）**：Tile 5 的 block=(1,1)，线程(1,2)即 t=33，负责像素(17,18)，地址1169。记录下标4、5、6由 t=0、1、2装入；t=33不加载却读取全部三项。再明确宣布换到258条候选的边界测试，第二批base=260、valid=2，已经done的t=1仍负责第二个槽。不要把两个不同列表混成同一个场景。
3. **复用收益与代价（第39页）**：假设256个像素全检查3项，只计一个FP32字段，global读取请求从768次变为3次；新增shared写3次、读768次。说明9 KiB是本讲按字段数组存放的教学缓冲区，不是官方kernel的资源报告，也不是性能实测。

GPU 25 分钟可按第32–39页分别安排 2、4、3、5、3、5、1、2 分钟。第35页不从头重教每个变量：先指出前页已经解释的加载，再追一个像素的内循环，最后看全块投票与两次交接。长代码可在演示卡片内滚动。

### 控制范围与超时处理

- 进入本讲前应能读懂第五讲的二维线程索引、第三讲的独占前缀和、第六讲的shared分块与两次交接。这里只做简短唤醒，不重讲scan树、CUDA安装或矩阵乘法。
- 几何主线建立“软覆盖 → 屏幕足迹 → 局部alpha”直觉；完整协方差变换、二次型展开放在深入页。SH基函数与损失形式放在最后的深入阅读中。学生无需推导这些公式才能完成三道练习。
- 第33页先观察加载分工表，再读7行代码；第34页指出valid限制读取范围；第36页要求说出“谁还需要t=1加载的数据”。把问答嵌入讲解，不增设额外测验。
- 若已消耗机动时间，优先压缩SH说明、训练细节与源码延伸；保留C/T次序、计数→Scan→排序、协作加载及done线程职责。性能实验设计页作为阅读提示，仍保留最后的整帧回顾。
- 若135分钟还必须包含两次5分钟休息，则可用教学时间为125分钟。应另外缩减内容，而不是挤掉全部提问空间：开场10、高斯11、投影11、合成20、Tile25、GPU25、训练7、性能6、机动10，共125分钟。

## 与原发布仓库的关系

原仓库只含已生成的公开站点，教师的编辑项目尚未提供。此实现不修改原来的压缩 JS/CSS，通过一个单独的本地草稿导航脚本，从现有主页与侧栏链接至新章。原有六讲保持其原有阅读与演示应用。

本地草稿没有编号为第七讲，以免与其他作者的 FlashAttention 等内容发生顺序冲突。没有更新发布清单，也没有执行部署。后续正式整合应将本目录的内容与图示迁入原作者项目，并通过其 `pnpm pages:prepare` 流程重新生成公开站点。直接运行旧项目的生成器可能覆盖本地生成页。

方法依据 Kerbl 等 SIGGRAPH 2023 论文（论文 HTML 标注 CC BY 4.0）及官方实现；正文保留来源链接。所有图解与数值小例子均为原创。没有重新分发官方 CUDA 源码。论文概念与本讲简化代码之间的差别在相关页面明确说明。

## 第2页：输入与输出的可视化

- `visual_io.py` 提供四步图文与静态点云图；`visual_io.mjs` 提供照片/相机切换、绕场景观察、从选定相机投影点云。PDF 展开四步，使用静态重建图。
- 先并排看 Garden 三张照片，再对应 A/B/C 的橙色视锥。锥尖位置和朝向来自外参，锥口张角来自 PINHOLE 内参；视锥的绘制深度仅为显示尺寸。点击“从相机看点云”可与该相机照片对照。
- Viser 示例数据含185个已配准视角、138,766个点。页面抽样16,000点及部分相机，裁剪远处点，再统一刚性变换坐标以便观察。三个视角的特征重投影误差中位数约1.07–1.13原图像素。
- `prepare_colmap.py` 解析现成的二进制 COLMAP 结果并核对重投影。重新提取：`python3 authoring/3dgs/prepare_colmap.py /path/to/colmap_garden.zip`。原始89 MB压缩包不加入仓库。
- 高斯形状用原创椭球参数图与原论文图3（Train场景）说明；椭球表示等值面，高斯没有硬外壳。最后展示论文中的Garden渲染结果，视角不同于照片A/B/C。没有在本机运行SfM或训练3DGS，也没有把教学椭球标成Garden训练参数。
- 照片、点云子集、图示和渲染图均随本地站点保存。第二步首次打开时才读取点云JSON。媒体来源与归属见 `media/SOURCES.md`。
